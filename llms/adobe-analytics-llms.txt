# Adobe Analytics

> Adobe Analytics provides real-time analytics and detailed segmentation across all marketing channels. The Adobe Analytics 2.0 APIs give programmatic access to reporting, segments, calculated metrics, dimensions, metrics, date ranges, annotations, and component administration — almost any action available in the Analytics UI. Companion APIs cover high-volume server-side data collection, real-time hit streaming, and privacy-driven data repair. Authentication is Adobe IMS OAuth (bearer access token) plus an Adobe Developer Console API key (x-api-key).

## APIs

- [Adobe Analytics API (2.0)](https://developer.adobe.com/analytics-apis/docs/2.0/): Reporting, segments, calculated metrics, dimensions, metrics, report suites, annotations, date ranges, tags. Base URL https://analytics.adobe.io/api/{globalCompanyId}
- [Bulk Data Insertion API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/bulk-data-insertion/): Upload server-side call data in compressed CSV batches. Base URL https://analytics-collection.adobe.io/aa/collect/v1
- [Livestream API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/livestream/): Real-time hit-by-hit streaming of processed traffic. Base URL https://livestream.adobe.net/api/1/stream
- [Data Repair API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/data-repair/): Permanently delete or transform previously ingested data for privacy compliance. Base URL https://analytics.adobe.io/api
- [Data Insertion API (1.4)](https://developer.adobe.com/analytics-apis/docs/1.4/guides/data-insertion/): Single-event server-side submission (excluded from the 1.4 EOL). Base URL https://sc.omtrdc.net/b/ss
- [Adobe Analytics 1.4 API (deprecated)](https://developer.adobe.com/analytics-apis/docs/1.4/): Legacy reporting/admin; end-of-life August 12, 2026.
- [Classification API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/classifications/): Import and remove classification values for dimension items.
- [Data Feed API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/datafeeds/): Create, update and manage raw-data feeds and column presets.
- [Data Warehouse API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/data-warehouse/): Schedule and retrieve Data Warehouse report requests.
- [Data Sources API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/datasources/): Manage data source uploads into a report suite.
- [Marketing Channels API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/marketingchannel/): Retrieve marketing channel processing rules.
- [Cloud Locations API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/cloudloc/): Manage cloud export accounts and locations.
- [Report Suite admin API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/reportsuites/): Create and administer report suites.
- [Component Migration API](https://developer.adobe.com/analytics-apis/docs/2.0/guides/endpoints/compmigration/): Map Analytics dimensions/metrics to Customer Journey Analytics.

## Agents & MCP

- [Adobe Analytics MCP server](https://developer.adobe.com/analytics-mcp/docs/aa/): Adobe-hosted remote MCP server at https://aa-mcp.adobe.io/mcp (23 tools; discover components + run reports in natural language).
- [MCP tool reference](https://developer.adobe.com/analytics-mcp/docs/aa/reference)
- [Adobe Analytics Agent Skills](https://github.com/adobe/skills/tree/main/plugins/adobe-analytics): Five Adobe-published SKILL.md capabilities (KPI pulse, top movers, conversion funnel, segment comparator, executive briefing) that run on the MCP server.
- MCP auth: OAuth 2.1 authorization_code + PKCE via Adobe IMS; scopes openid, AdobeID, additional_info.projectedProductContext. Anonymous tools/list returns 401.
- No A2A agent card is published on any Adobe Analytics host (probed 2026-08-13).

## SDKs

- [@adobe/aio-lib-analytics (JavaScript, official)](https://www.npmjs.com/package/@adobe/aio-lib-analytics)
- [aanalytics2 (Python, community)](https://pypi.org/project/aanalytics2/)
- No first-party Adobe client library exists for Java, .NET, Go, Ruby, PHP or Rust for the 2.0 REST API; the official Adobe packages in those ecosystems are client-side data-collection SDKs (alloy for web, AEP/ACP mobile SDKs), not API clients.
